# Support

## Where to ask

Open a GitHub issue on this repository. Include the command that you ran, the domain that you tested, and the output that you got.

## In scope

- Bugs in detection, scoring, parsing, or the MCP protocol.
- Wrong or missing service fingerprints. Include the DNS records that prove the gap.
- Documentation errors.

## Out of scope

- Deliverability consulting. For domain warmup as a service, see [warming.email](https://warming.email).
- Support for platforms below macOS 13.
- Requests to probe hosts on your behalf.
